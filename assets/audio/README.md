# Музыка

`music.wav` — **собственная** фоновая музыка игры, композиция и рендер скриптом `tools/gen_music.py`
(без сэмплов и чужого аудио; результат детерминирован). Спокойная зацикленная мелодия: мягкий пэд,
бас, калимба, редкая пентатоническая мелодия; 16 тактов, 72 BPM, около 53 с, шов цикла убран.

Звуковых эффектов у игры сейчас нет: версии на встроенных звуках движка и на синтезированных
не понравились владельцу и удалены.

## Как включить

1. Прослушайте `music.wav`. Если не нравится, правьте `tools/gen_music.py` (аккорды `CHORDS`, темп `BPM`,
   громкости и тембры голосов) и запустите `python3 tools/gen_music.py`.
2. Загрузите файл как **Audio** (Creator Hub → Creations → Audio → Upload, либо Open Cloud
   `POST /assets/v1/assets`, `assetType = Audio`, `audio/wav`, нужны права `asset:read`/`asset:write` и
   разрешение папки в Studio Assistant → MCP Permissions) на аккаунт, которому принадлежит experience.
   Лимит Roblox: 10 загрузок в месяц без верификации личности, 100 с верификацией. Дождитесь модерации.
3. Впишите `asset = "rbxassetid://<id>"` в `src/shared/Config/Music.luau`. Пока `asset = ""`, музыки нет.

Громкость регулируется ползунком «Музыка» в настройках (`SoundGroup` `Music`).
