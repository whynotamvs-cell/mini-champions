# PUBLISHING.md — подготовка к публикации MVP

Чек-лист для владельца. Публикует только владелец; ассистент ничего не публикует и не сохраняет в облако без явного разрешения.

## 1. Аудит сети (проверено по коду, не в Studio)

Все RemoteEvent/RemoteFunction регистрируются через `Net.onServerEvent/onServerInvoke`: у каждого есть rate limit и валидатор аргументов, ненормальные вызовы считаются нарушениями.

| Remote | Что присылает клиент | Защита |
|---|---|---|
| `PurchaseUpgrade` | индекс улучшения (целое 1..N) | 2/с; баланс и владение проверяет `ClubService` |
| `SendEmote` | id эмоции | enum из `Emotes.Ids`, кулдаун |
| `UpdateSettings` | таблица настроек | `SettingsLogic.sanitize`, 4 за 2 с |
| `TutorialAck` | шаг (только допустимое значение) | 2/с; сервер проверяет состояние |
| `RequestRestart`, `RequestSnapshot`, `RequestBoard` | ничего | 1/с |

Клиент не присылает ни времени забега, ни наград, ни баланса: забег, время, медаль и награда считаются на сервере (`ObstacleDash`, `DashRewards`, `grantId`). Текстового ввода, видимого другим игрокам, нет.

## 6. Платные предметы: что создать в Creator Hub

Список и ориентиры цен — `docs/ECONOMY.md` раздел 9. Для каждого предмета создать Developer Product (или Game Pass для `spring`) и вписать его id в `src/shared/Config/Shop.luau` (`RobloxId`). Пока id равен 0, предмет в магазине показан как «Скоро».

- [ ] `skip`, `stars_small|medium|large`, `trail_*`, `finish_*` — Developer Products.
- [ ] `spring` — Game Pass.
- [ ] Протестировать покупку каждого товара дешёвой ценой (тестовый режим продаёт настоящие Robux).
- [ ] Проверить, что повторный чек не выдаёт товар второй раз (повторить `ProcessReceipt` для одного `PurchaseId`).

## 7. Иконка и миниатюры

Нарисованы скриптом `tools/gen_store_art.py` (нужен Pillow), результат в `assets/store/`: `icon.png` (512×512, квадрат) и `thumb_1..3.png` (1920×1080). Всё рисовано с нуля, питомцы и кубок свои.

Загрузка через Creator Hub (Edit → Experience → Icon / Thumbnails) или Open Cloud (`PATCH /assets/v1/assets/{placeId}?updateMask=icon|previews`, scopes `asset:read/write`, папка `assets/store` должна быть в разрешённых для загрузки). Загружать в **релизный** опыт; картинки проходят модерацию Roblox.
